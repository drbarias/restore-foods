🔑 One-Time Setup
To save new entries directly to your catalog, you need a GitHub Personal Access Token. This is stored only on your device — it never leaves your browser.

How to get your token:
1. Go to github.com/settings/tokens/new
2. Name it: restore-foods
3. Set expiration: No expiration
4. Under Scopes, check repo (the first checkbox)
5. Scroll down → click Generate token
6. Copy the token (starts with ghp_) and paste below
